# AP Web — демоверсии сайтов для локального бизнеса

Готовый набор из **трёх интерактивных статических демо-сайтов** для презентации услуг веб-разработки.

## Онлайн-примеры

После включения GitHub Pages:

- **Каталог:** https://apestalina-byte.github.io/ap-web-business-demos/
- **TurboFix Garage (автосервис):** https://apestalina-byte.github.io/ap-web-business-demos/examples/auto/
- **North Cut (барбершоп):** https://apestalina-byte.github.io/ap-web-business-demos/examples/barber/
- **ДомПодКлюч (ремонт и отделка):** https://apestalina-byte.github.io/ap-web-business-demos/examples/repair/

## Функциональность

- Адаптивная вёрстка для компьютеров и телефонов.
- Плавные переходы и анимации появления (учитывается `prefers-reduced-motion`).
- Автосервис: услуги, кейсы и демонстрационный калькулятор.
- Барбершоп: мастера, выбор услуг и демонстрационный сценарий записи.
- Ремонтная компания: проекты, этапы и демонстрационная оценка стоимости.
- Формы **не сохраняют и не отправляют данные на сервер**. Они открывают профиль разработчика в Telegram и предлагают отправить подготовленный текст самостоятельно.
- Никаких реальных платежей, личных кабинетов или API-ключей.

## Локальный запуск

Откройте `index.html` в браузере или запустите локальный статический сервер:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000/.

## Публикация

Рекомендуемый репозиторий: `apestalina-byte/ap-web-business-demos`, ветка `main`, GitHub Pages публикует `/(root)`.

Скрипт `publish_business_demos_new_repo.ps1` (поставляется отдельно) создаёт репозиторий через GitHub CLI, загружает файлы и пытается включить Pages. Для этого нужны Git for Windows и GitHub CLI. Авторизация подтверждается через браузер GitHub.

## Важное ограничение

Все названия компаний, показатели, отзывы, мастера и описания выполненных работ — **иллюстративные примеры**, а не сведения о действующих предприятиях. Никакая заявка на услуги этих компаний не отправляется.

Фотографии загружаются с `images.unsplash.com` по внешним HTTPS-ссылкам и требуют интернета. Для реального клиентского сайта необходимо заменить их на собственные или лицензированные фотографии клиента.
