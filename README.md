# AP Web — сайты для малого бизнеса

Четыре самостоятельные статические страницы: витрина AP Web и три интерактивных демонстрационных сайта. Стек: семантический HTML, CSS и JavaScript без сборки и внешних runtime-зависимостей.

- Витрина: `index.html`, небольшой сайт от 9 900 ₽ с отдельным согласованием объёма и интеграций.
- КОНТУР: `examples/auto/index.html`, категории и подробности услуг, расчёт работ, галерея, обращение.
- ТИХО: `examples/barber/index.html`, прайс, демонстрационные профили мастеров, галерея, выбор нескольких услуг, даты и условного слота.
- ЛИНИЯ: `examples/repair/index.html`, фильтры интерьерных референсов, галерея, площадь и состав ремонта, расчёт и копируемый бриф.

Публичный адрес: https://apestalina-byte.github.io/ap-web-business-demos/

## Демонстрационный режим

Компании вымышлены. Указанная география — часть концепции. Реальных адресов, телефонов, рейтингов, отзывов и бронирований нет. Суммы условные. Две бизнес-формы формируют бриф, третья дополнительно показывает демозапись; сервер ничего не получает. Копирование и открытие Telegram выполняются отдельными действиями. Контакт @artem10p принадлежит разработчику сайта. Персональные данные не сохраняются, аналитики, платежей и запросов к Alingua нет.

Три демостраницы содержат `noindex,follow`; главная витрина открыта для индексации. После адаптации для настоящего бизнеса настройки индексации, данные и метаданные пересматриваются.

## Структура

`assets/base.css` и `assets/common.js` содержат общий интерфейс: навигацию, фильтры, галерею, копирование и анимации. Отдельные CSS и JS отвечают за характер и логику каждой страницы. Фотографии локальные, WebP. Источники и ограничения описаны в `ASSET_LICENSES.md` и `IMAGE_CREDITS.json`.

## Локальный запуск

Из корня проекта: `python3 -m http.server 8080`. Откройте http://localhost:8080/.

Без сборки. GitHub Pages публикует корень ветки `main`. Для переезда на другой домен обновите Open Graph URL и изображения в HTML.

## Проверка

- `python3 tests/check_static.py` — страницы, локальные ресурсы, якоря, метаданные, изображения и отсутствие сетевых отправок в JavaScript.
- `node --check assets/common.js` и аналогично для остальных JS.
- Ручная браузерная проверка: навигация, формы, калькуляторы, галереи, клавиатура и меню.
- Браузерные измерения на 320, 375, 390, 430, 768, 1024, 1440, 1920 px.
- axe-core 4.10.3: WCAG 2 A/AA и WCAG 2.1 AA, мобильная и десктопная ширина. Детали — в приложенном отчёте проверки.

Движок реальной записи, CRM, backend и настоящая смета в этот проект не входят.
