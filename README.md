# AP Web / Business Demos — редакционный редизайн

Три независимых демонстрационных сайта для малого бизнеса. Сайты созданы для показа потенциальным клиентам: они **не представляют реальные компании**, не содержат настоящих отзывов, рейтингов, адресов или заказов.

## Примеры

- [Главная портфолио](index.html)
- [КОНТУР — автосервис](examples/auto/index.html): индустриальная типографика, список услуг, процесс, демо-обращение.
- [ТИХО — барбершоп](examples/barber/index.html): редакционная композиция, прайс, фотография, выбор услуги и времени.
- [ЛИНИЯ — ремонт и отделка](examples/repair/index.html): архитектурный минимализм, услуги, проектные изображения, краткий бриф.

**Публикация:** https://apestalina-byte.github.io/ap-web-business-demos/

## Принципы

- Нет вымышленных коммерческих показателей и «отзывов», которые можно принять за настоящие.
- Три разные дизайн-системы, без иконок-эмодзи, псевдо-3D, глянцевых карточек и кислотных градиентов.
- Чистый HTML, CSS и JavaScript, без сборщика и зависимостей.
- Прогрессивные анимации входа в поле зрения; поддержка `prefers-reduced-motion`.
- Адаптивная сетка, клавиатурная навигация, мобильное меню.
- Демоформы создают текст обращения, копируют его и открывают Telegram [@artem10p](https://t.me/artem10p). Пользователь отправляет сообщение вручную.
- Нет аналитики, cookies, backend и сохранения персональных данных.

## Фотографии

Все визуальные иллюстрации включены в архив в локальном формате WebP. Это специально созданные для демоверсии фотореалистичные изображения, **не фотографии действующих компаний и не подтверждение реальных работ**. Перед запуском коммерческого сайта они должны быть заменены подлинными фотографиями бизнеса либо лицензированными кадрами. Права на использование и релевантность фотографий должны быть повторно проверены перед коммерческим использованием в проекте клиента; в живых проектах лучше использовать собственную фотосъёмку бизнеса. Демо не заявляет фотографии как реальные работы компаний.

## Публикация

Содержимое папки — корень GitHub Pages-репозитория `apestalina-byte/ap-web-business-demos`, источник `main`/`root`.

## Проверка

Проверить `index.html` и страницы `examples/*/index.html` на десктопе и мобильном экране. В режиме `file://` локально доступны страницы, стили и скрипты; внешние фотографии требуют доступа к Unsplash. Для локального HTTP-просмотра: `python -m http.server 8080`.
